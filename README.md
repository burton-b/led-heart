# LED Heart Display

An Arduino-based heart made of 28 LEDs, with a buzzer, a brightness knob and a pattern button. Flip the switch and it plays a song while the LEDs twinkle at random, then settles into a set of light patterns you can cycle through.

## How it works

| Switch | What happens |
|--------|--------------|
| DOWN | Everything off. Resets the display. |
| UP | The song plays with random LEDs lighting up on each note, then the pattern mode starts. |
| DOWN again | Instantly turns everything off and resets. |
| UP again | The song plays again from the start. |

After the song, press the pattern button to cycle through 5 patterns:

1. **All on**: steady glow
2. **Pulse**: fades up and down
3. **Spiral**: LEDs fill in one by one, then clear in reverse
4. **Alternate**: even and odd LEDs trade places
5. **Heartbeat**: double flash with a buzzer tick, like a pulse

A pot (potentiometer) controls brightness at any time.

## Features

- 28 LEDs driven directly from digital and analog pins, with PWM brightness control
- Buzzer melody (Twinkle Twinkle Little Star) generated by bit-banging square waves, with no tone library
- Random LEDs light up on each note, and longer notes light several at once
- The switch is checked inside every pattern, so turning it off cuts the lights immediately
- Debounced pattern button

## Pin map

| Pin | Function |
|-----|----------|
| 2-13, A1, A2 | 14 LEDs |
| A0 | Brightness potentiometer |
| A3 | Power switch (UP = on) |
| A4 | Pattern button |
| A5 | Buzzer |

## Build / upload

1. Open `led_heart.ino` in the Arduino IDE.
2. Select your board and port.
3. Upload.
